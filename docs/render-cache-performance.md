# 建筑贴图缓存与动态帧优化

本批继续四阶段方案的第四阶段。只修改 `gfx/sprites.cpp` 与 `game/game_render_world.cpp`，Scene30 / NativeProduction4 / World56 / App11 / LAN46 均保持。模拟、规则、资源文件及存档布局未改；完整对局矩阵、主循环追帧、人工实玩、完整支援任务与其余战役仍在进行。

## 已定位与修正

使用真实 8 人中盘 App11，在工具副本中对输入、资源解析和绘制子过程加嵌套计时。原程序的已缓存建筑贴图每帧仍先调用 `bldSpriteStem`；未选中建筑也会查图片并解析选中笼框。600 帧采样平均每帧调用该查找 550.28 次，资源候选文件检查 2832.06 次；建筑查找嵌套 CPU 耗时约 11.77ms。这些计时相互包含，不能相加。

现在 `SpriteBank::building` / `buildingGhost` 先检查既有贴图缓存，未命中时才解析资源；选中笼框只在实际选中时解析和绘制。没有引入新的路径缓存，既有国家/阵营图片选择、构造模式、调色板和颜色缓存键保留。选中笼框的尺寸、偏移和画法保持原样。

相同的无建筑选中采样中，预热后的建筑查找由 550.28 次/帧降为零，资源候选检查降至约 0.31 次/帧。命中查询和绘制仍执行原有逻辑，不用减少单位、修改迷雾或降低模拟频率来换取成绩。

## 配对动态结果

同机 AMD Radeon 610M，使用优化前保存的程序和优化后程序执行相同驱动、相同真实中盘 App。每项 120 帧预热、600 帧测量；固定 30Hz 模拟/60Hz 绘制比例，包含真实输入、模拟/AI、绘制及 `glFinish`。画布为 1440×810，输出为 1280×720 或 1920×1080。以未加细分计时的程序判断性能，仪器副本只用于定位。

| 样本 | 优化前整帧 p95 / p99 | 优化后整帧 p95 / p99 |
| --- | ---: | ---: |
| RA2 4 人，1280 | 12.40 / 14.64ms | 5.51 / 8.15ms |
| RA2 4 人，1920 | 12.72 / 15.20ms | 6.19 / 8.69ms |
| YR 8 人，1280 | 20.32 / 28.14ms | 8.64 / 17.22ms |
| YR 8 人，1920 | 20.80 / 29.32ms | 9.03 / 17.16ms |

四项受控样本的 p95 均达到本机 16.67ms 目标。每项初始 App、最终 World 和实际输出 PNG 与修改前逐字节相同；指令尝试、实际回执、接受数量及起止模拟摘要分别一致。另用四个国家、六类建筑、选中笼框/放置预览和双输出尺寸检查了 96 个画布帧摘要及八对实际 PNG，均与修改前相同，渲染前后 World 摘要保持不变。

相关 Release 35/35（254.98 秒）、ASan 35/35（1204.28 秒）通过，无失败或跳过，未报告内存错误。两种构建各保留 50 条经济、68 条支援和 77 条规则一致性断言；14 对本批实际保存跨构建逐字节相同，10762 项冻结输入在检查结束时未变化。本批没有重跑完整全量。

并行扩展的四局自然对局中，RA2 八人岛屿及四人湖泊分别在 198716 / 235966 tick 结束；YR 四人陆地、八人陆地在原定 360000 tick 内未决胜。68 个 App11 检查点均精确续跑，四局资金、来源身份及存活方经济检查通过，不能因此将超时改判通过。四人失败存档另行继续到 638578 tick 自然结束，15 个检查点仍精确；电脑丢失建造厂后重复购买基地车的问题已转入后续修复。并行对局耗时受竞争影响，不计入性能结论。

检查选择集、原始日志摘要、冻结输入、图像/保存对照和自然对局结果位于 `review_out/frame-performance-20261117/validation.json`。其中 `renderCacheVerified=true`，而包含两局超时的总覆盖 `ok=false`，整体项目仍未完成。

## 继续处理

预热最大帧仍约 212ms。去掉文件查询后，第 143 个测量帧仍有约 17.5ms 落在 `pickUnit` 内的单位贴图取得/生成路径；具体缓存未命中和姿态生成还需进一步记录。另有帧同时执行 AI 思考和迷雾遮罩更新。这些是下一步细分与优化的依据，不能把 p95 达标解释为没有偶发卡顿。

本结果是两个真实中盘的受控短测，不覆盖实际主循环的累计时间、追帧/丢帧策略、完整长局峰值或真实 OS 输入。下一步继续核对单位命中区域取得贴图的成本、姿态预热和迷雾更新，保持点击结果、显示及模拟一致；同时扩大剩余人数/地图/种子、人工操作与原版战役验收。
