# 原始事件条件、局部变量与卸载

本批继续第一关事件解释器，接入发现、受击、生产类型、选中与局部变量条件，以及原始卸载和设定局部变量脚本。它不是完整战役或原机逐帧一致性的证明。

当前格式为 **World46 / App10 / SourceScene14 / NativeEvents4 / NativeProduction1 / NativeAI1 / NativeCrates1 / LAN24**。原图的 738 个初始对象保持不变；补入任务队伍引用的 SAPC 运行时定义后，总定义为 109，军队/建筑资料为 74。

## 条件语义

- **4：Discovered**。追踪来源对象被各个人类房屋发现的记录，开局视野静默初始化；之后实际视野首次发现其他房屋的对象才提供通知。带有真实攻击来源的致死路径也在死亡通知前提供发现通知。以来源对象键保存，不依附可复用的实体编号。
- **6：Attacked**。在实际扣除正伤害后提供通知；攻击来源必须仍是有效实体。友军和同房屋来源也算受击；没有来源、零伤害和被免伤规则拒绝的命中不算。该条件不被记忆。
- **19–22：Build Type**。每个房屋分别记录建筑、车辆、步兵与飞机最后实际出厂的原始类型编号。开局对象、增援和精炼厂赠送矿车不写生产历史；堵门而未出厂的订单也不写。原图车辆索引 33 为 CMIN、步兵索引 3 为 ENGINEER，不能使用混合的运行时类型索引或规则表的原始行键代替。
- **33：Selected**。仅由新的本地人类选择意图提供，参数不参与判断。点击、框选和编队提供第一个新选择，同类选择可提供所有新选择；音频关闭、渲染和音频消费不能触发。该通知走 `World::Cmd`，局域网输入不发送此类意图，线协议也拒绝它。来源身份校验防止陈旧选择作用于复用编号的新对象。
- **36/37：Local Set/Clear**。保留 50 个局部变量槽。原图声明变量 0 默认关闭、变量 1 默认开启。值真的改变时重置所有引用该变量的触发器计时，同值赋值不重置；下一次普通条件遍历检查结果。动作 56/57、队伍脚本 39/40 共用该入口。

NativeEvents4 的条件仍逆序检查。生产事件能够开启条件记忆，已记忆的时间性条件保持已满足；Elapsed Time 是持续条件，不再记录为时间性标记。历史 NativeEvents1–3 保留旧解释边界，旧来源不会因新程序而自动改用这些语义。

语义依据包括固定版本的 [OpenTS 源码](https://github.com/OpenTS-Developers/OpenTS/tree/4e5fd62e930339a03c2c18be53a43a167fcf9a79/code) 中 `tevent.cpp`、`team.cpp`、`techno.cpp`、`house.cpp` 和 `building.cpp`，以及 [触发机制说明](https://opents-developers.github.io/OpenTS/systems/trigger-springing/)。这些是可追溯的实现依据，不能代替 RA2 实机校准。

## 原始卸载脚本

脚本 8 使用真实登载和连通出口释放乘员，保存正在卸载的乘员来源键；冻结或出口受阻时保留乘员与游标。释放后按来源键找回实际实体并加入队伍，不制造替代步兵。参数 2 释放运输工具、保留实际卸载的队员，随后脚本 39 设定局部变量，原作者的撤退触发器可以创建队伍并招募释放的船只。

原始 SAPC 使用 TRS 素材、300 HP、900 造价、12 容量、15 自身尺寸和 6 的乘员尺寸上限。陆水移动沿用现有两栖模拟；原始速度、转向和完整出入水行为仍待校准。

共用卸载入口现会拒绝冻结载具，报告保留人数和冻结原因。发现记录在完整帧后清理已消耗的工程师等身份，同时保留已经进入容器的乘员身份，避免旧身份破坏存档或让乘员重新出现时重复发现。

## 验证范围

`native_conditions_assets_test.py` 独立核对来源注册表、两条变量声明、两个生产条件、SAPC 数据和卸载/局部变量脚本。

`ra2.native_conditions` 复用真实 Tanya 入区、基地交接、兵营建造和付费工程师流程，再验证实际 GI 出厂会替换最后步兵类型。选中分支使用实际训练的 GI；发现、受击和运输分支明确使用隔离对象、标签附着或组装状态，不冒充原图自然时间线。

运输分支通过真实登载命令装入五名来源 E2，再明确组装原始队伍并进入其卸载行。冻结期间检查乘员和待卸载身份续档；恢复后验证五人保持来源身份、船只被原作者的撤退队招募，以及后续逐 tick 继续一致。还验证实际 World45/Scene13 旧档、陈旧选择身份、应用续档、异常布尔值、类型索引、身份、数量与截断记录。
