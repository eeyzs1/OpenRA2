# 默认快捷键（RA2）

可在游戏选项中重绑。下列为经典默认（Stephanus FAQ / 原作习惯）。

## 控制

| 键 | 功能 |
|----|------|
| A | 切换与所选对象主人的结盟（多人） |
| C | Cheer |
| D | 部署 / 解除部署 |
| G | 守卫 |
| X | 散开 |
| S | 停止 |
| Z | 路径点规划模式 |

## 界面

| 键 | 功能 |
|----|------|
| Esc | 选项 |
| K | 维修模式 |
| L | 出售模式 |
| Ctrl+C | 截图 |
| Q | 建筑页（再按可抓取已完成建筑） |
| W | 防御页 |
| E | 步兵页 |
| R | 单位页 |
| Space | 跳转雷达事件 |
| B | 放置信标（多人） |
| H | 回基地 |
| Num5 | 居中所选 |

## 选择

| 键 | 功能 |
|----|------|
| P | 选中战斗单位（再按扩到全图） |
| T | 同类型选择 |
| N / M | 下一/上一对象 |
| Y | 按军衔过滤所选 |
| U | 按血量过滤所选 |

## 编队

| 键 | 功能 |
|----|------|
| Ctrl+0–9 | 创建编队 |
| 0–9 | 选择编队（再按可居中） |
| Shift+0–9 | 加入编队 |
| Alt+0–9 | 居中编队 |

## 书签

| 键 | 功能 |
|----|------|
| Ctrl+F1–F4 | 设地图书签 |
| F1–F4 | 跳转书签 |

## 底栏（Advanced Command Bar）

原作六键：Team01、Team02、TypeSelect、Deploy、Guard、PlanningMode。  
Stop/Scatter 仅键盘。详见 `docs/ra2-ui-fidelity.md`。
