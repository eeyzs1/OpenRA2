# 战役通用机制

遭遇战规则见上级 `mechanics.md` 等。本页只列**战役模式特有**或显著不同的机制。

## 1. 流程骨架

```text
选阵营 → 关卡列表 → FMV/简报 → 载入地图 → 执行目标 → 胜利/失败 FMV → 下一关
```

- **简报**：实拍演员（Eva / Zofia / 将军 / 罗曼诺夫 / 尤里等）+ 地图目标列表。
- **过场 VQA**：西木招牌绿幕 FMV；风格见 `../style/assets.md`。
- **难度**：通常影响敌方经济/攻击强度/某些计时，不改变主线目标文本。
- **Par Time**：社区攻略常记“标准完成时间”，非强制失败条件（除非关卡另有限时目标）。

## 2. 胜利 / 失败

| 类型 | 示例 |
|------|------|
| 歼灭 | 消灭地图上全部敌军单位与建筑 |
| 摧毁关键建筑 | Psychic Beacon / Amplifier / Dominator / 核弹井 / Chronosphere 等 |
| 占领 | 工程师占领指定建筑（Battle Lab、白宫、机场等） |
| 护送 / 存活 | 保护 Einstein 实验室、罗曼诺夫、谭雅等 |
| 限时 | 在时限内摧毁心灵信标（如 Free Gateway） |
| 多阶段 | 中途追加目标（Lone Guardian 接触基地后再拆补给点） |

**英雄死亡即败**在多关出现（尤其 Tanya 早期关）。复刻时必须把“指定单位死亡 → Lose”做成触发器。

## 3. 地图脚本（原作概念 → OpenRA2 映射）

原版用地图触发器（时间、进入区域、建筑毁、占领、计数等）。OpenRA2 已抽象：

| 原作意图 | OpenRA2 `TrigCond` / `TrigAct`（见 campaign.h） |
|----------|--------------------------------------------------|
| 定时刷兵 | `Time` + `SpawnAt` |
| 单位进入区域 | `UnitInRect` |
| 某建筑全毁 | `PlayerBldLost` |
| 玩家全灭 | `PlayerAllDead` |
| EVA 提示 | `Eva` |
| 更新目标条 | `Objective` |
| 给钱 / 揭雾 | `GiveMoney` / `RevealMap` |
| 胜负 | `Win` / `Lose` |
| 复杂逻辑 | `Script` → Lua |

官方关卡的精确触发仍在 `.map` 内；本文档只定义**玩家可观察契约**。

## 4. 科技与单位解锁（战役节奏）

- 战役按关**逐步开放**科技树，不等于遭遇战开局满科技。
- 部分单位**仅战役出现**或更早出现：如 RA2 盟军战役中的 SEAL；苏军战役 Psi-Corps；YR 月球 Cosmonaut。
- 国家特有单位可能在对应地点关卡强调（法国巨炮、德国黑森林等）。

## 5. 战役专用建筑 / 装置

| 名称 | 作用 |
|------|------|
| Psychic Beacon | 心灵信标：控制区域平民/部队；通常必须摧毁以解放或推进 |
| Psychic Amplifier | 更强心灵设施（如芝加哥）；常需在上线前摧毁 |
| Psychic Dominator | YR 核心超武建筑；战役多关围绕其展开 |
| Time Machine | YR 开局装置；需供电并存活；可触发时间旅行事件 |
| Einstein Lab / Chronosphere 原型 | 需保护或摧毁（阵营线不同） |
| 白宫 / 五角大楼 / 克里姆林宫等 | 地标目标（占领或摧毁） |

心灵信标效果：范围内敌对单位可能被心控或平民敌对化——具体以该图脚本为准；玩家侧表现为“必须拆信标才能正常作战/完成目标”。

## 6. 增援与脚本事件

常见模式：

- 定时或条件满足后 **伞兵 / 两栖运输 / 舰队 / 谭雅小队** 抵达
- 地图扩大（如 Dark Night 渗透实验室后揭示核弹井区域）
- 断电：间谍进电厂使线圈失效（战役教程向）
- 桥梁：工程师修桥屋；海豹/谭雅/伊万炸桥
- 中立科技：医院、油田、机场在关卡中作节奏点

## 8. 合作战役（YR）

YR 增加多人合作任务（盟/苏/尤里各有合作关）。机制：共享目标、分路推进；尤里**仅有合作、无单人剧情线**。

## 9. 复刻验收清单（战役层）

1. 每关：地点、主目标、失败条件（含英雄死亡）可单元测试或脚本断言。  
2. 关键目标能更新 HUD（`Objective`）。  
3. 关键建筑（信标/超武井）毁坏能触发胜负。  
4. FMV/简报可缺资源，但目标文本与触发逻辑不能缺。  
5. 不把遭遇战满科技默认套进早期战役关。
