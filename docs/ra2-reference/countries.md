# 国家特色单位与能力

RA2：盟军 5 国 + 苏军 4 国。YR：+ YuriCountry。  
规则里部分国家倍率被注释掉，遭遇战实际特色以 **专属单位 / 支援** 为主（`Owner=` 限制）。

## 盟军

| 国家 | rules ID | 特色 |
|------|----------|------|
| 美国 | Americans | **Airborne**：空指部后伞兵（约 8 GI，冷却 4:00）；可与科技机场伞兵并存 |
| 英国 | British | **Sniper**（$600）：远距一击步兵 |
| 法国 | French | **Grand Cannon**（$2000，-100 电）：超远对地溅射 |
| 德国 | Germans | **Tank Destroyer**（$900）：UltraAP，极克坦克，几乎不伤步兵/建筑 |
| 韩国 | Alliance | **Black Eagle**：替代 Harrier，HP/伤害更高（Cost 同 1200，HP 200，Maverick2） |

共用：GI、Guardian GI(YR)、Rocketeer、Spy、SEAL(YR)、Tanya、Chrono Legionnaire、全套盟军载具海军等。
