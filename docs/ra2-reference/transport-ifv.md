# IFV 乘员武器矩阵与运输容量

## 1. IFV（Infantry Fighting Vehicle）

空载默认：`HoverMissile`（对空火箭，HE）。装入 1 名步兵后炮塔/武器切换。

| 乘员 | 武器效果（玩法） |
|------|------------------|
| 空 / Attack Dog | 对空导弹 |
| GI / Conscript / Spy / Initiate 等基础步兵 | 机枪 |
| Guardian GI | 对地/对空相关强化（YR） |
| Flak Trooper | 高射炮 |
| Engineer | 维修臂：修车、清恐怖机器人 |
| Sniper | 狙击 |
| SEAL / Tanya / Chrono Commando / Psi Commando | 重机枪 |
| Desolator | 辐射炮 |
| Crazy Ivan / Chrono Ivan / Terrorist | 自杀/炸弹类 |
| Tesla Trooper | 特斯拉 |
| Yuri / Yuri Clone | 精神冲击穹 |
| Brute | 近战相关（若允许装载） |
| 部分中立/特殊 | 棱镜等 |

精确 Turret/Weapon 映射以 `artmd.ini` + rules 的 IFV 系统为准；上表为遭遇战可读对照。

## 3. 装载限制提醒

- 正在心控 / 被心控的单位通常不能进运输。
- 心控运输时，舱内单位往往仍属原主人。
- Crazy Ivan 一般不能直接炸运输舱内逻辑目标（手册：不对运输绑弹）。

## 4. 载具易主与乘员归属

普通RA2从Scene56起，载具被尤里等易主后，普通货舱乘员仍归原玩家，卸载恢复为该玩家单位；原生IFV炮手同样保留原归属。嵌套运输分别解析各层归属。仍与活动心控/寄生对象相连的乘员沿用已有登车拒绝，同盟登车和人类外交界面不属于此项改动。

归属随World75保存，嵌入既有World64..74基础布局；旧Scene55及更早、YR43与融合规则继续旧行为。原版依据为四组实际Gunner标志开关、炮手模式绑定、Unit/Foot易主链与列表出队的隔离执行。普通乘员及炮手都保留原归属；Unit+0x5b0并非炮手，该初期误判及修正证据均保留。尚未执行完整原版步兵构造、物理卸载或帧循环。详细边界与哈希见`tests/fixtures/ra2-cargo-ownership-reference.json`。


## 5. 地面运输逐名卸载

普通RA2从Scene57起，Unload登记地面运输任务，按准备、释放和收尾推进，每次只恢复一名乘员。已转正的静止夹具在命令后第5个逻辑tick首次释放，之后间隔28～32tick（来源`[Unload] Rate=.016`：截断`.016×900`得到14个原版帧，再加0～2个随机帧；一原版帧对应两逻辑tick）。重复下达不会重置进度；获准移动或停止等新命令会中断，余下乘员留在车内。原有移动路线可以完成后再卸载。释放阶段的出口受阻保留乘员并等待重试；准备时没有出口则结束此任务。

IFV释放炮手时才恢复空载武器；等待期间仍有炮手。乘员归属继续按Scene56的逐名记录恢复。活动任务使用World76，同时保留World75的归属块与World64..74的基础布局；Scene56及更早、YR43、融合、空中运输和驻军保持各自旧流程。

本节Scene57时序的原版依据是三种种子下实际Mission_Unload、MissionClass::AI计时、乘员列表、RNG和立即Move队列的隔离执行。Scene57保留原有出口搜索、车体朝向与离舱后行为；Scene58的更新见下节。项目首派发对齐未证明等同原版鼠标输入。物理放置等依赖与哈希见`tests/fixtures/ra2-ground-unload-reference.json`，不据此声称完整卸载复刻。


## 6. 出口、车体朝向与离舱

Scene58补齐地面运输的出口选择和离舱方向。原版出口评分包含有符号方向比较、南向扣分及大于零的门槛，因此不能统一替换成“最近空格”。例如平地全开放时，朝北的普通载具会选择西南出口并请求车体转向东北；相邻格只有北侧可用时也可能没有正分出口。IsTrain分支保留当前量化朝向，该标志已在原程序的INI绑定中确认。

车体完成转向后，乘员从相邻格出现，并获得向同方向第二格移动的指令。若找不到近/远格同时开放的方向，再尝试偏移1..7的近格；第二轮不包含正后方偏移0。释放失败继续保留乘员等待，已有重复下令、中断与归属合同继续生效。无须增加存档版本，当前已有World76/GND1可保存转向与卸载阶段。

这是原始查询、派发与受控近/远格捕获的校准，项目保留自身的地表、占位与路径准入；原版完整物理Unlimbo、步兵子格与完整输入派发仍未校准。Scene57旧档保持其原环形落点及续跑结果。


## 7. 同盟乘员

普通RA2从Scene59起，已有同盟关系的单位可以借用运输，仍受尺寸、容量、部署和控制器关联等准入限制。运输方检查其对乘员方的关系，鼠标动作还保留乘员方的敌对检查。载具由原玩家控制；乘员玩家不能借此移动或卸空载具。舱内及卸载后的乘员仍属原玩家，包括IFV炮手，同舱可以同时保存载具方和同盟方的乘员。

World/App沿用既有显式归属与逐名卸载合同。Scene58及更早、YR43与融合继续同一所有者登车。当前机制用例使用既有AI结盟关系，不代表人类外交界面或共享单位控制已经实现。原版查询、选定动作尾部和乘员列表执行及其外围依赖见tests/fixtures/ra2-allied-boarding-reference.json。


## 8. 同格装载

普通RA2从Scene60起，步兵或获准的地面车辆必须实际进入运输器所在XY格才会转成舱内记录。运输器偏离格心时也以同格为接触条件。载机仍在空中时乘员先在邻格等落地，保持落地点空闲；落地后再走入同格。接近走普通路径，只对当前获准载具的物理占位放行，其他占位、地形、桥层、载机落地、尺寸与容量规则继续生效。两栖运输在乘员无法通行的水格时必须先驶到乘员可达处，不能由邻岸交互范围隔格装载。

Scene59及更早、YR43和融合保留旧1.6格范围，建筑入口保持原合同。同盟乘员归属、IFV炮手绑定及分阶段卸载沿用已有实现。原版选定转移分支的200位置与11前提对照见tests/fixtures/ra2-transport-boarding-reference.json；完整原版命令、机车接近和帧调度尚未校准。
