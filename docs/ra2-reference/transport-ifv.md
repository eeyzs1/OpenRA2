# IFV 乘员武器矩阵与运输容量

## 1. IFV（Infantry Fighting Vehicle）

空载默认：`HoverMissile`（对空火箭，HE）。装入 1 名步兵后炮塔/武器切换。

| 乘员 | 武器效果（玩法） |
|------|------------------|
| 空 / Attack Dog | 对空导弹 |
| GI / Conscript / Spy / Initiate 等基础步兵 | 机枪 |
| Guardian GI | 对地/对空相关强化（YR） |
| Flak Trooper | 高射炮 |
| Engineer | 维修臂：修车、清恐怖机器人 |
| Sniper | 狙击 |
| SEAL / Tanya / Chrono Commando / Psi Commando | 重机枪 |
| Desolator | 辐射炮 |
| Crazy Ivan / Chrono Ivan / Terrorist | 自杀/炸弹类 |
| Tesla Trooper | 特斯拉 |
| Yuri / Yuri Clone | 精神冲击穹 |
| Brute | 近战相关（若允许装载） |
| 部分中立/特殊 | 棱镜等 |

精确 Turret/Weapon 映射以 `artmd.ini` + rules 的 IFV 系统为准；上表为遭遇战可读对照。

## 2. 常见运输容量

| 单位 | 容量 | 可运 |
|------|------|------|
| IFV | 1 | 仅步兵 |
| Flak Track | 5 | 步兵 |
| Nighthawk | 5 | 步兵；雷达隐身 |
| Amphibious Transport | 12 槽 | 步兵+车辆（车辆占多槽） |
| Battle Fortress | 多步兵 | 全员可开火；可碾压车辆 |
| Bio Reactor | 5 | 步兵供电 |
| Battle Bunker | 若干征兵 | 驻军射击 |
| Tank Bunker | 1 车 | 有炮塔非炮兵车辆 |

## 3. 装载限制提醒

- 正在心控 / 被心控的单位通常不能进运输。
- 心控运输时，舱内单位往往仍属原主人。
- Crazy Ivan 一般不能直接炸运输舱内逻辑目标（手册：不对运输绑弹）。
