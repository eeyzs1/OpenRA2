# 间谍渗透、免疫表与机制勘误补丁

补充 [mechanics.md](./mechanics.md)；若冲突以本页 + `rulesmd` 为准。

## 1. Force Shield（YR，全阵营）

建造 **Battle Lab** 后充能，盟/苏/尤里皆有。

| 项 | 值 |
|----|-----|
| 效果 | 范围内友方**建筑**无敌（含超武） |
| 持续 | 约 25 秒 |
| 代价 | 整基断电约 60 秒 |
| 单位 | 不影响；不杀步兵 |
| 与铁幕 | 可覆盖已有铁幕建筑保护 |

## 2. 间谍渗透矩阵

Spy 伪装后进入敌方建筑（犬可识破）：

| 目标 | 效果 |
|------|------|
| 电厂 / 核电 / 生化堆 | 短暂断电 |
| 雷达 / 空指 / 心灵雷达 | 雷达重置 / 迷雾相关干扰 |
| 精炼厂 / 奴隶矿 | 窃取资金 |
| 兵营 | 己方步兵出老兵 |
| 战争工厂 | 己方车辆出老兵 |
| 船厂 | 己方海军相关老兵（若适用） |
| 空指部 | 与雷达/空军渗透相关 |
| Battle Lab（盟军） | 解锁 Chrono Commando |
| Battle Lab（苏军） | 解锁 Chrono Ivan（或 RA2 下 Yuri Prime，视版本） |
| Battle Lab（尤里） | 解锁 Psi Commando |
| 超武建筑 | 重置/拖延超武冷却（引擎具体行为以 rules 为准） |

## 3. 心控免疫（常见）

通常免疫心灵控制：

- Chrono Miner / War Miner / Slave Miner（矿车体系）
- Attack Dog
- Terror Drone、Chaos Drone、Robot Tank
- 飞机（Harrier、Kirov、Rocketeer、Disc 等多数空中单位）
- 其它心控单位（Yuri Clone、Mastermind 等）
- 英雄：Tanya、Boris、Yuri Prime
- 铁幕中的单位
- 驻军中的步兵（尤其 Dominator）
- Giant Squid / Dolphin 等部分有机海军（视武器/规则）

Yuri Prime 可心控**建筑/防御**（Clone 通常不能）。

## 4. 碾压

- 多数坦克可碾压普通步兵。
- **不可碾压**示例：Tesla Trooper、部分英雄、Brute（犬也不咬 Brute）。
- Battle Fortress 可碾压车辆。
