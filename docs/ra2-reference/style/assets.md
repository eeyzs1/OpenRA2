# RA2 素材格式与风格管线

定义原作资产形态，以及 OpenRA2 对齐时的风格约束。技术验收见 `docs/ra2-ui-fidelity.md`。

## 1. 原作资产类型

| 格式 | 用途 | 风格含义 |
|------|------|----------|
| **SHP** | 步兵、建筑、动画、UI、光标 | 8-bit 索引色帧；RLE-Zero；含阴影帧 |
| **VXL + HVA** | 载具、部分炮塔 | 体素模型 + 动画；可旋转倾斜 |
| **TMP** | 地形模板 | 等距菱形格 60×30 |
| **PAL** | 调色板 | 256 色；含玩家 remap 区 |
| **AUD / audio.bag** | 音效语音 | 压缩单声道流 |
| **VQA** | 过场 FMV | 实拍演员 + CG 合成（西木招牌） |
| **MIX** | 打包容器 | 原版资源封装 |
| **Cameo SHP** | 侧栏图标 | 统一斜角玻璃小画 |

## 2. 调色板纪律

典型约定（TS/RA2 系）：

| 索引区 | 用途 |
|--------|------|
| 0 | 透明 |
| 1–15 | **玩家色 remap** |
| 中段 | 通用固有色 |
| 高段 | 动画循环色 / 特效 |
| 阴影 | 独立帧，常用特殊索引 |

新美术若走 PNG 导入，必须能 **量化回官方/项目 PAL**，并正确保留 remap 与透明，禁止直接 32-bit 贴图「看起来差不多」。

## 3. Cameo 规范

- 小尺寸、可读剪影。
- 传统：角上键色、内斜边、轻度玻璃高光。
- 进度由 `gclock2` 扫臂表现，图标本身不转。
- 侧栏顺序跟 rules 声明序，**不按造价排序**。

## 4. 世界物件规范

| 项 | 要求 |
|----|------|
| 建筑锚点 | 钉占地南角；阴影跟地基 |
| ActiveAnim | 油田泵臂、医院灯等循环层 |
| 中立科技 | Remapable=no |
| 缺 VXL | 允许近亲车体占位（APOC→MTNK 等），**逻辑 ID/数值/SFX 不变** |

## 5. 过场与实拍风（若做战役）

- Westwood FMV：真人演员绿幕 + 简陋 CG 背景，刻意「廉价科幻」魅力。
- 不要改成现代影视级预渲染；保持戏剧夸张与幽默。

## 6. OpenRA2 三条路径（architecture）

表现层已有：程序精灵 / PNG overlay / VXL。  
**新艺术优先走资产 overlay**；不要再平行发明第四套外观系统。
