# OpenRA2 风格定义：指挥壳（方向 B — 同谱系工业现代）

对战前菜单 + ESC/设置等壳层的视觉语言契约。  
UV：`menu-screens.md`；学习对照：`gui-study-notes.md`；世界：`art-visual.md`。

> **已锁定：方向 B**（用户 2026-08）。  
> v3 扁平方框/冰蓝描边墙 **作废**。气质对齐 Tempest Rising 一类「升级过的西木指挥台」：有材质、强调稀缺、冷钢调可，但禁止网页后台壳。

---

## 0. 一句话

**指挥壳 = 工业现代战争仪器：钢板面板有凹凸，命令字偏暖琥珀，强调色只打在焦点/主行动；L0 氛围与侧栏同属一个金属世界。**

`LOAD_*` 槽位冻结。

---

## 1. 气质坐标

| 轴 | 我们在哪 | 明确不在哪 |
|----|----------|------------|
| 身份 | Tempest / Remaster 同谱系当代仪器 | SaaS 侧栏、学生扁平方框 |
| 材质 | 钢面板、凹槽、钮面、顶亮底暗 | 单色矩形 + 全员彩边 |
| 色温 | 冷钢底 + 暖琥珀命令字 | 冰蓝描边墙、黄字复刻刷屏 |
| 强调 | 悬停/主钮才亮钢青或琥珀 | 每个框都描强调色 |
| 导航 | 仪器钮（居中字、零件感） | 左强调条 + 左对齐网页列表 |

---

## 2. 三层结构

```
L0  load/BIK 弱贴（同世界金属氛围）
L1  内容洞：深凹钢板底
L2  侧栏仪器：标题板 · 凹入监视器 · 动作钮
```

- L0 可淡贴 `load` 侧栏纹理，再罩钢板程序层——**有材质，不是纯平灰**。
- 禁止左洞 RA2 雷达框 vs 右栏网页导航的撕裂感。

---

## 3. 色票（实现常量）

| Token | 约 RGBA | 用途 |
|-------|---------|------|
| `ink` | `236,210,150` | 命令字（暖琥珀，非荧光黄） |
| `inkHot` | `255,236,190` | 悬停字 |
| `inkMute` | `140,148,160` | 次要 |
| `steel` | `28,32,40` | 面板主体 |
| `steelDeep` | `12,14,18` | 凹槽/监视器井 |
| `steelHi` | `78,86,98` | 顶/左明边 |
| `steelLo` | `8,10,14` | 底/右暗边 |
| `accent` | `72,168,196` | **稀缺**钢青（悬停顶缘、主焦点） |
| `heart` | `48,58,72` → 悬停略提亮 | 钮面，非整边描强调 |

危险/移除：暖红字或微红罩，少用。

---

## 4. 控件族

| 族 | 画法 |
|----|------|
| **Plate** | 钢板 fill + 顶亮底暗边（无彩描边墙） |
| **Well** | 更深凹槽（值槽、监视器） |
| **TitleBtn / SideBtn** | 钢板钮面 + 内缩；悬停：顶缘钢青细线 + 字提亮；按下：明暗对调微下沉；字**居中** |
| **ValueSlot** | Well；悬停才钢青边 |
| **Tip** | 深半透明井，细钢边，无角标刷屏 |

禁止：左轨强调条当主识别、全员 `DrawRectangleLinesEx(accent)`。

---

## 5. 贴图纪律

- 脏 SHP 勿硬拉；程序面板必须有 inset 明暗
- 侧栏可淡贴 load 裁切作 L0，主可读靠程序钢板
- 禁非整数 scale 下 Gradient 作钮面主填充

---

## 6. 验收

`ra2.exe --gui-review` 自视：

- [ ] 能看出面板凹凸（不是空心框）
- [ ] 强调色稀缺（不是每个矩形都彩边）
- [ ] 侧栏像仪器栏，不像后台导航
- [ ] 与左洞 BIK 同属金属世界
