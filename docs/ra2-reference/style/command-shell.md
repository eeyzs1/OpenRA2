# OpenRA2 风格定义：指挥壳（Command Shell）

本文是 **对战前菜单 + 局内 HUD 壳层** 的视觉语言契约，供人与 AI 共同遵守。  
玩法保真见 `docs/ra2-fidelity.md`；壳层 UV/素材对照见 `menu-screens.md`；世界画风见 `art-visual.md`。

---

## 0. 一句话

**指挥壳 = 2000 年西木 RTS 的工业仪表盘：真实像素贴图当主角，程序只补洞，禁止发明第二套 UI。**

OpenRA2 不是「致敬 RA2 的现代游戏」，而是 **站在原作壳层上玩融合内容**（中国阵营、共和国之辉战役等）。融合可以加内容，**不能换皮肤语法**。

---

## 1. 气质坐标

| 轴 | 我们在哪 | 明确不在哪 |
|----|----------|------------|
| 时代 | 2000–2001 PC RTS，CRT / PCB / 军用仪表 | 2020s SaaS 面板、赛博霓虹、玻璃拟态 |
| 情绪 | 冷战戏谑 + 重工业压迫感；黄字冷静下令 | 可爱、二次元、蒸汽波、军事纪录片写实 |
| 材质 | SHP/PCX 里的金属、铆钉、红亮心、战术地图纹理 | 程序渐变金属、假 PBR、大面积纯色圆角卡 |
| 信息密度 | 偏高；一屏说完遭遇战 | 大留白「精致」落地页 |
| 动效 | 少而硬：悬停扫光帧、勾选闪一下 | 缓动弹跳、模糊、粒子铺满 |

**融合身份怎么露脸**：阵营色、国旗、单位 cameo、战役文案可以带中国/共和国之辉符号；**壳层几何、按钮族、字色体系不变**。中国是第四个「房客」，不是房东改装门面。

## 2. 三层结构（永远先想层，再想控件）

```
┌─────────────────────────────────────────────┐
│  L0  场景皮  BIK / titlelg / load / multi   │  ← 整页情绪
├──────────────────────┬──────────────────────┤
│  L1  内容洞           │  L2  侧栏 PCB + CRT  │  ← 原作 UV 冻结
│  选项 / 玩家表 / 地图 │  标题条·监视器·动作钮 │
└──────────────────────┴──────────────────────┘
         ↑ 控件只活在洞里或侧栏格里，禁止漂浮卡片
```

- **L0**：只换皮，不改分区。主菜单用 BIK/标题；遭遇战/选项用 `load`；联机用 `multi`。
- **L1**：深色洞 + 战术地图底（`content_map`），上面叠表格式控件，不是白卡片。
- **L2**：右栏永远是「仪器」：监视器看东西，下面按钮下命令，标题条声明当前屏。

局内 HUD 另有侧栏 cameo 体系，但遵守同一气质：**金属面板、像素图标、青金钱字、硬阴影黄字**。

## 3. 色票（实现用常量，禁止临时霓虹）

菜单逻辑色（640 画布上）建议固定为：

| Token | RGBA | 用途 |
|-------|------|------|
| `shell.ink` | `232,196,72,255` | 主文字（金黄，非荧光黄） |
| `shell.inkHot` | `255,236,140,255` | 悬停文字 |
| `shell.inkMute` | `160,150,120,255` | 次要说明 |
| `shell.danger` | `255,120,90,255` | 危险/高难度，少用 |
| `shell.panel` | 来自贴图 | 禁止用纯 `#1a1a1a` 大方块冒充壳 |
| `shell.tipBg` | `6,8,10,240` | tip 叠层，窄用、短文 |
| `shell.crt` | 监视器内近黑 | 可有极弱扫描感，不要彩虹示波玩具感 |

**红亮心**：理想上是干净的 `sdbtn*` / `sdmpbtn*` 像素；当前提取件含雪花时，**主路径用程序柔光回退**（暗、淡、无噪点），禁止硬拉脏贴图冒充。

阵营识别色（盟蓝 / 苏红 / 尤里紫 / 中国红金）只用于 **单位 remap、旗帜、阵营徽**，不要重做成整页主题换肤。

## 4. 字体与字阶

| 阶 | 约略字号（逻辑 px） | 用途 |
|----|---------------------|------|
| Title | 14–15 | 侧栏标题条 |
| Body | 11–12 | 选项标签、按钮字 |
| Compact | 9–10 | 表头、拥挤槽内 |
| Tip | 10–11 | 监视器说明 |

规则：

- spacing = 0；1px 硬黑影（`drawTextS`），不要柔边描边。
- 字必须点采样放大；糊字 = 风格破产。
- 中文可以略挤，但 **禁止** 为塞字把按钮竖向乱拉导致贴图变形。

## 5. 控件族（有名字的零件，禁止再发明第四种按钮）

| 族 | 资产 | 比例契约 | 行为 |
|----|------|----------|------|
| **TitleBtn** | `sdbtnbkgd` + 悬停 `sdbtnanm` | ≈ 156×42，可略缩宽，**勿加高扭曲红心** | idle 贴底板；hover 播扫光帧 |
| **SideBtn** | `sdmpbtn_*` | ≈ 156×83 比例，宽可 ≤148 | 只用帧切换（idle/hover/press），**禁止再叠程序红光** |
| **ValueSlot** | `optbtn_00/01` | 高保持 ≈18，宽可拉 | 横向贴满；箭头用 `dropdown` |
| **Pip** | `pips_00/01` | ≈10×7 可略放大到 14×10 | 橙圆灯，不做 iOS 开关 |
| **Slider** | 程序轨 + 琥珀针 | 矮轨 | 离散档，工业指针不是 Material slider |
| **Tip** | 监视器内叠字 | 短标题 + 2–4 行正文 | 可关（`ui_tips`）；不要鼠标旁大气泡抢戏 |

遭遇战玩家行、设置分区头，都是 **表格式工业表单**，不是卡片列表。

## 6. 动效与声音（克制）

| 允许 | 禁止 |
|------|------|
| 悬停换帧 / 扫光循环 | 按钮缩放弹跳 |
| 勾选瞬时翻转 + Click | 长 fade、模糊过渡 |
| tip 即时替换监视器下半文案 | tip 飞入、打字机效果 |
| 下拉面板硬切出现 | 毛玻璃、阴影漂浮层 |

听觉：短促 UI Click；不要给每个悬停都配音。

## 7. 反模式（「廉价 / AI 感」检查表）

出现任一条，视为风格违规：

1. **霓虹盖贴图**：在 `sdbtn`/`sdmp` 上再画高饱和实心红条。  
2. **假金属**：大面积 `guiMetalFill` + 自绘 bevel 代替已有 `optbtn`/`load`。  
3. **万能圆角卡**：内容洞里出现现代卡片、阴影、大圆角。  
4. **荧光黄字**：`255,236,64` 一类刺眼黄铺满。  
5. **比例扯皮**：把 42 高的主菜单钮拉成 50+，或把 83 高的侧栏钮压成 42 扁条。  
6. **示波玩具**：监视器里花哨多色正弦「科技感」盖过信息。  
7. **第二皮肤**：为中国/融合内容单独换一套蓝紫渐变菜单。  
8. **留白海报**：主菜单侧栏按钮间距拉成落地页 CTA。

## 8. 融合内容怎么放进指挥壳

| 可以 | 不可以 |
|------|--------|
| 国旗、阵营徽、国家名出现在玩家槽 | 整页换成「中国风水墨壳」 |
| 战役选关文案、简报语气偏共和国之辉 | 按钮改成国潮插画按钮 |
| 第四阵营色出现在单位/建造 | 选项页主题色随阵营跳变 |

融合是 **叙事与单位表的扩展**；指挥壳是 **跨阵营的司令部家具**。

| 素材来源 | `tools/ra2pack/gen_menu_gui.py` → `assets/gui/menu/` |

新增控件前先问：**能否复用上表五族之一？** 不能，再开新族并写进本文第 5 节。

## 10. 验收口令（改完自己问）

1. 截掉文字，只看侧栏按钮贴图，能否认出这是 RA2 菜单而不是通用 HTML 皮肤？  
2. 关掉所有程序光效回退，主路径是否仍可读？  
3. 悬停主菜单钮时，红是 **扫光帧** 还是 **方块红布**？  
4. 值槽高度是否仍约 18px 逻辑高？  
5. 中国/融合内容出现时，壳层几何有没有被改掉？  

任一题不及格 → 回第 7 节查违规项。
