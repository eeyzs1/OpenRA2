# RA2 视效 (VFX) 定义

## 1. 原则

RA2 视效是 **精灵动画 + 调色板特效**，不是粒子物理电影。可读性优先于真实感。

| 要 | 不要 |
|----|------|
| 短帧动画、亮色闪光、明确弹道 | 屏幕填满烟雾导致丢单位 |
| 弹头决定溅射/辐射/电弧形状 | 统一「火球+火星」模板 |
| 建筑动画循环（烟、灯、雷达） | 静态贴图无生命感 |
| 迷雾/裂缝/铁幕有状态色 | 全屏模糊、运动模糊滥用 |

## 2. 武器视效语言

| 武器族 | 视觉 |
|--------|------|
| 子弹 (M60 等) | 枪口闪光、曳光点 |
| 坦克炮 | 短焰 + 命中小爆 |
| 高射/防空 | 空中黑絮/爆炸云 |
| 特斯拉 | 电弧折线，可跳目标 |
| 棱镜 | 直线亮束；塔间折射可见 |
| 辐射 | 地编绿色毒区，持续 |
| 心灵 | 波纹/紫环，少实体弹 |
| 超时空抹除 | 目标相位闪烁至消失 |
| V3/无畏导弹 | 可见飞行体，可被防空打爆 |
| 核弹 | 大圈闪光 + 蘑菇云感 + 残留辐射地编 |
| 铁幕 | 单位/建筑变色（经典偏黑/金属闪） |
| Force Shield | 建筑罩能量场，短时 |

## 3. 环境与状态 VFX

- **损伤**：建筑冒烟、着火帧；不要 PBR 破洞贴花。
- **低电**：防御停火即可，可用灯暗动画暗示。
- **生产**：工厂门口出单位；扫臂在 UI 不在世界。
- **矿**：矿车挖矿靠 VXL 姿态，无独立挖矿 SHP。
- **水**：舰船尾迹简单；潜水单位半隐。

## 4. 超级武器演出

| 超武 | 演出要点 |
|------|----------|
| Chronoshift | 选区闪白/相位，落点再现 |
| Weather Storm | 多段落雷，区域持续 |
| Iron Curtain | 立即变色无敌 |
| Nuke | 长飞行预警 + 落地毁灭 + 辐射 |
| Genetic Mutator | 生物畸变闪光，变 Brute |
| Psychic Dominator | 精神冲击波 + 建筑受损 |

建造超武时：**通知所有玩家 + 揭开该建筑迷雾 + 可见倒计时**——这是信息设计，也是「视效/UI」的一部分。

## 5. 性能与保真

- 同屏爆炸做对象池/上限，优先保留「玩家正在看的」特效。
- 新 VFX 优先 SHP/动画帧，其次简单程序粒子；避免引入与西木调色板冲突的 HDR 光晕。
