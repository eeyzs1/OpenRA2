# RA2 音乐风格定义

## 1. 作者与定位

- 作曲：**Frank Klepacki**（Westwood）
- 基调：高能量 **工业金属 / 电子摇滚**，回应玩家对《泰伯利亚之日》偏氛围配乐的意见，回归《红色警戒》式肾上腺素。
- 标志曲：`Hell March 2`（HM2）——行军鼓、军令采样、失真吉他。

常用设备语境（原作者）：Korg TR-Rack、Novation Nova、Roland XV-5080。

## 2. 听觉关键词

| 要 | 不要 |
|----|------|
| 失真电吉他 riff、军鼓、工业打击乐 | 史诗管弦好莱坞大片（RA3 方向） |
| 合成器贝斯、快速 4/4 | 环境 Ambient 主导整局 |
| 短小循环友好、战斗中可无缝 loop | 人声流行歌、歌词叙事主歌 |
| 阵营可共用曲库，靠选曲情绪区分 | 每国完全独立现代 OST 专辑结构 |

## 3. 官方曲目参考（RA2 OST 节选）

`HM2` · `Industrofunk` · `Ready the Army` · `Grinder` · `In Deep` · `Motorized` · `Power` · `200 Meters` · `Destroy` · `Burn` · `Probing` · `Blow It Up` · `Eagle Hunter` · `Fortification` · `Jank` · `C&C In the House`

Yuri's Revenge 保持同族能量，可增加更「精神/诡异」音色层，但仍应是 Klepacki 工业金属语法，而非恐怖游戏垫乐。

## 4. 使用场景建议

| 场景 | 音乐行为 |
|------|----------|
| 菜单 | HM2 或高识别主题；可完整播 |
| 建造扩张 | 中速工业曲（Motorized / Power） |
| 大战 | 更快、更密 riff（Destroy / Burn） |
| 潜入/尤里 | 可降调性、加不协和合成器，但鼓点仍在 |
| 胜利/失败 | 短 stinger，不要冗长 |

## 5. OpenRA2 约束

- 不可重新分发受版权保护的原版音轨到仓库；文档只定义**风格目标**。
- 若用原创替代：必须通过「闭眼能听出是 RA2 气质」测试——吉他+军鼓+工业，而非通用 RTS 管弦。
- 响度：战斗 SFX 优先；音乐床应让开 EVA/开火（见 [sfx-voice.md](./sfx-voice.md)）。
