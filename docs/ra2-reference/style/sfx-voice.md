# RA2 音效与语音定义

## 1. 语音层级

| 层级 | 角色 | 气质 |
|------|------|------|
| 盟军 EVA | Lieutenant Eva（Athena Massey） | 清晰美式女声，专业、冷静、略带俏皮 |
| 苏军 | Lieutenant Zofia（Aleksandra Kaniak） | 口音俄语风女军官，干脆、命令式 |
| 尤里 | 尤里本人等 | 低沉、精神控制感、威胁性停顿 |
| 单位选中/移动/攻击 | 各单位专用台词 | 短、可spam、有性格（伊万疯狂、谭雅自信等） |

EVA/Zofia 负责：**建造完成、基地受攻、超武就绪、低电、发现敌人** 等全局事件，不是每个点击都念。

## 2. SFX 分类

| 类 | 示例 | 设计要点 |
|----|------|----------|
| UI | 点击侧栏、放建筑、雷达叮 | 金属短音；延迟极低 |
| 武器 Report | 机枪、坦克炮、特斯拉、棱镜 | 一枪一报；**攻击音宜短（≤约 0.35s）** 以免重叠糊成一片 |
| 爆炸 | 建筑塌、V3、核弹 | 低频冲击 + 碎片；核弹要有残留感 |
| 移动 | 履带、蹄步、喷气 | 循环或步进；距离衰减 |
| 特殊 | 心控、超时空、铁幕、辐射 | 有独特音色 ID，玩家应「听声识技能」 |
| 箱子 | CrateMoney / CratePromote / … | 每种增益不同提示音 |

原作音频容器：`audio.bag` 等，常见 **mono IMA ADPCM，ChunkSize=512**（见 `docs/ra2-ui-fidelity.md`）。

## 3. 混音原则

1. **语音 > 武器 > UI > 音乐**（冲突时压音乐）。
2. 同屏大量开火时依赖短 Report + 限流，而不是加长尾混响。
3. 立体声：爆炸可有方向感；EVA 语音居中。
4. 不要对一切加现代「游戏预告片」whoosh。

## 4. 单位语音性格样例

| 单位 | 应有性格 |
|------|----------|
| GI / Conscript | 普通大兵，短应答 |
| Crazy Ivan | 狂笑、俄语爆破感 |
| Tanya / Boris | 英雄口吻，短句有记忆点 |
| Yuri Clone | 低语、精神波 |
| Kirov | 缓慢、沉重、俄语飞艇报告 |
| Spy | 轻声、伪装相关 |

## 5. OpenRA2 验收

- `WeaponDef.report` 映射到专用样本，禁止「所有枪一个 bang」。
- 解码参数与 ChunkSize 对齐，避免变速/爆音。
- 缺编资源可用近亲占位，但 **Report 名不得错绑**。
