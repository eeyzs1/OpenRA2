# RA2 视觉画风定义

OpenRA2 表现层应对齐的 **Red Alert 2 / Yuri's Revenge** 视觉语言。验收细节另见 `docs/ra2-ui-fidelity.md`。

## 1. 总体气质

| 维度 | 定义 |
|------|------|
| 时代感 | 2000–2001 西木 RTS：卡通夸张冷战科幻，非写实军事模拟 |
| 情绪 | 幽默、高饱和、英雄主义；苏军厚重、盟军干净科技、尤里诡异紫调 |
| 镜头 | 固定 **等距斜 45°** 俯视；不可自由旋转 3D 相机 |
| 禁止 | 现代 PBR 写实、泛光赛博、扁平 Material UI、写实战争摄影风 |

## 2. 构图与比例

- 地格：**源 TMP 60×30** 菱形格 → 引擎可映射为 64×32，比例保持 `BLD_SCALE = 64/60`。
- 单位相对格：步兵娇小；主战坦克约占 1 格视觉重量；建造厂/超武明显大于坦克。
- VXL：约 **1 voxel ≈ 1 原作像素**；禁止再额外 fit 放大（如 ×1.22）。
- 阴影：SHP 独立阴影帧；画在主体之下；索引色体系，非实时软阴影。

## 3. 阵营视觉识别

| 阵营 | 建筑/涂装印象 | 色彩 |
|------|----------------|------|
| 盟军 | 合金、玻璃、棱镜蓝白 | 冷蓝、银灰、白 |
| 苏军 | 钢板、铆钉、锈红五星 | 深红、褐铁、黄黑警戒 |
| 尤里 | 有机曲线、颅骨/眼球、悬浮 | 紫、品红、病态绿 |

玩家色通过调色板 **remap 区（索引约 1–15）** 染色；中立科技/油田等 **Remapable=no**，禁止被染成阵营色。

## 4. UI 画风

- 侧栏：深色金属面板 + 像素图标（Cameo）。
- Cameo：小尺寸、内斜角/玻璃高光、四角透明键色传统；**不要**扁平圆角 App 图标。
- 金钱：侧栏 **青色像素数字 + 深描边**，点采样，非 7 段 LED、非矢量字。
- 生产进度：`gclock2.shp` 扫臂；cameo **不旋转**。
- 鼠标：`mouse.shp` 多帧动画光标（Move/Attack/Deploy/Sell/Repair/AttackMove…）。

## 5. 地形

- 温带/雪地/城市/月球等主题 TMP 模板。
- 岸线、悬崖靠模板与变体，**不做跨格模糊 lerp 糊缝**。
- 矿：亮绿（矿）/亮蓝（宝石）结晶簇，高对比可读。
- 迷雾：战争迷雾遮罩；原作有 `shroud.shp` 瓦片语言。

## 6. 单位造型语言

| 类型 | 媒介 | 造型要点 |
|------|------|----------|
| 步兵 | SHP 多面向 | 剪影清晰；部署态（沙袋/辐射）动作可读 |
| 载具 | VXL + HVA | 炮塔可 360°；坡上倾斜；体块夸张 |
| 建筑 | SHP 为主，炮塔可 VXL | 动画：烟囱、雷达碟、泵臂、灯 |
| 飞机 | SHP/逻辑飞 | 影随形；机场停机位对齐 |

## 7. 验收口令（给美术）

1. 缩到侧栏图标大小仍能认出单位。
2. 去掉玩家色后，仍能靠外形区分盟/苏/尤里。
3. 不依赖现代后处理也能在迷雾/夜色下辨认敌我。
4. 新资产必须能落入 8-bit 调色板工作流（见 [assets.md](./assets.md)）。
