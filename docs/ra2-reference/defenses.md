# 防御与超级武器

含墙、主动防御、支援建筑、超武与国家支援能力。造价/电力/机制以 CNCNZ 为主；HP 以 GameFAQs YR Guide 为主。

## 通用规则

- 多数主动防御 **低电停火**（碉堡/哨戒炮/墙除外）。
- 爱国者 / 高射炮等可拦截部分飞行单位与来袭导弹（V3、无畏舰导弹等）。
- 墙可阻挡地面单位；一次可沿已有墙段连续放置最多约 4 段。

### 棱镜塔联动

多座棱镜塔靠近时，可通过互相照射把光束叠加到同一目标，显著提高伤害。断电则全部停火。

### 特斯拉线圈充能

- 特斯拉步兵靠近自动充能：提升射程与威力。
- **≥3 名**特斯拉步兵充能时，线圈可在**低电下仍工作**。
