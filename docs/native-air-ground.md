# 飞行单位的地形探测与装卸命令

RA2／尤里来源规则已接通夜鹰的持续装卸命令、地面接触检查、可用落点搜索及 Jumpjet 高度探测。规则为 Scene23 / JumpjetVersion2，World54 保存待办和重试时间；App11 外层不变，LAN38 区分新的模拟行为。影片继续排除。 后续机场机位与付费生产修复使用 LAN39，见 [机场与生产](airfield-production.md)。

## 直接影响对局的问题

| 问题 | 当前处理 | 验证范围 |
| --- | --- | --- |
| 夜鹰在空中立即放下乘员，附近步兵也可瞬间登机 | 卸载先降落；登机指令让夜鹰停下并降落，步兵等待实际接触地面 | 两套来源规则的真实乘员、移动、装卸及途中续档 |
| 降落后出口受阻就丢失原命令 | 保留待办，每 30 tick 有限重试；部分卸载保留剩余乘员顺序、来源身份和状态 | 关闭／打开出口、部分卸载、实际保存和自动完成 |
| 重复卸载指令不断重置落点和搜索时间 | 已排队的命令保持原任务，后来的移动、攻击、停止或警戒可以取消它 | 重复请求校验和不变、新移动保留乘员 |
| 水面或车辆占据目的地，直升机无法找到落点 | 寻找附近合法地面／桥面；没有落点时悬停并保存有限重试时间 | 受阻目的地、全水面、高地岸边出现后的继续执行 |
| 中止下降半帧后残留 0.5 高度，永远不落地 | 原版 Move_To 的下降→上升转换接入新模型；取消剩余下降时对齐整数高度 | 最后下降半步中出现车辆，平滑升起并飞到邻格 |
| 在桥面降落、部署或卸载时占据下方水层 | 使用桥面高度和层号，占位及乘员出口保持在正确表面 | 供给高度 6 桥面／高度 2 水面的几何夹具，独立舰船在下方通过 |
| 没有桥的地图忽略接近路径的目标高度 | 指定高度的范围寻路也检查高度；落地装卸遵守坡度和连通出口 | 陡坎下登机拒绝、陡坎外卸载拒绝、同层出口打开后自动完成 |

反馈区分“正在降落”和“等待出口”，不会在接受待办时显示已卸载成功。冻结保留未完成任务；恢复模拟后可以继续降落及卸载。非法布尔值、过远的重试时间和不属于该机体的落地任务会拒绝保存或加载；损坏应用存档不会替换正在运行的对局。

## 原程序对照

本地 `GAME.EXE` SHA256 仍为 `fe67fdac5073530a79baec14c4e072b5e7e4c0c462cee9659870c5330e9e6e3e`。新的隔离 Win32 探针实际调用以下原函数，不启动游戏入口、不修改原文件：

- `0x4916d0`：初始化八方向的一格坐标偏移；同时验证方向边界和 65535 回绕。
- `0x531140`：取得当前／前方格的 Jumpjet 高度参考。
- `0x47a290`：在供给的地面及对象列表上计算障碍高度。
- `0x45d8b0`：取得原始建筑尺寸中的高度。

29 组结果覆盖上坡、下坡、奇数高度、桥面、建筑、其他占位和静止状态。原函数在前方地形更高时直接采用前方高度，下降时则混合当前和前方样本，不能一律取最大值。桥面修正和建筑高度进入同一计算。来源包保留普通建筑的原始 art Height × 104，普通对象的原函数分支会增加 85 lepton。

探针供给地面／对象回调、104 lepton 层高、416 lepton 桥梁增高及活动状态标志，因此它证明这些函数在供给样本上的计算与方向取样，不能证明原版地图坡面内部插值、覆盖物全部几何、邻近落点搜索顺序或完整单位 AI。World 的落点搜索采用确定的圈层、距离、y、x 次序，属于当前工程实现。独立 YR 可执行程序的对照仍缺失。

## 搜索开销

搜索只访问每一圈的边界，避免随半径反复扫描已经检查过的方框内部；距离相同时保持固定 y、x 次序。没有落点时每 30 tick 重试，重复命令不会绕过此限制。

本机预检在 256×256 全水面夹具上直接调用 32 次搜索，由总计 208.979ms、平均 6.531ms 降到总计 8.731ms、平均 0.273ms。此测量不含创建世界，不代表整局帧率。最终冻结版本的测量另在本批验证 JSON 中记录。
