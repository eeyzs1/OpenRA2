# 来源遭遇战随机补给箱

本轮工作区为 **World55 / App11 / 来源规则 Scene26 / 原版地图 Scene16 / LAN43**。影片恢复排除。

本轮最终验证已完成。下文说明实现和证据范围；具体日志、哈希、普通对局及存档记录保存在本地 `review_out/project-review-20261115/source-crates-validation.json`。

## 修复内容

此前来源遭遇战仍使用融合原型的十一种等概率奖励：钱箱固定给 1,000，单位箱按玩家阵营固定赠送基础坦克，升级主要依靠临时计时器。这个路径忽略原始 Powerups 权重和 CrateGoodie；原始规则中的灰熊、犀牛和狂风都不是普通单位箱奖励。

新来源包导入全部十九条 Powerups 原始记录、权重、水上可用性和 Data。两套本地原始规则中实际非零的八种奖励为钱、单位、基地治疗、地图揭示、护甲、速度、火力和经验；零权重不表示额外效果已实现，含未支持非零效果的包会被拒绝。融合规则继续保留自身路径，原版第一关作者脚本箱继续使用 NativeCrates v1。

随机奖励在拾取时抽取。钱箱使用原始 Data=2,000，加上 0～900 的随机值；战役作者钱箱的 SoloCrateMoney 路径保持独立。

普通单位箱从原始 VehicleTypes 列表筛选 CrateGoodie，保留原始顺序和原始来源身份，不套用生产科技、前置条件或阵营筛选。缺少 CrateGoodie 时默认关闭；本地 RA2 普通池为十种、尤里为十三种，海战覆盖后分别为六种和九种。肉搏战及海战的原始例外均保留，包括不能生产但仍能从箱子获得的车辆。

符合条件的无基地玩家会优先获得本国 MCV；有建造厂而没有矿车时，单位箱优先给本国矿车。水上不允许的奖励转成钱箱。普通 AI 的多余基地车筛选、车辆数量上限和固定 UnitCrateType 也进入奖励选择。精确的放置搜索顺序、载具内对象计数以及更多采集者边界仍需独立校准。

护甲、速度和火力使用保存的来源对象倍率，已升级采集者再次拿到同类奖励时转成钱箱。范围内符合条件的敌方对象也能获得升级。经验箱将军衔和用于后续击杀的经验值同步到晋升边界，避免只显示老兵却仍需从零积累经验；部分经验的新人同样提升至边界。经验值换算使用引擎已有的 VeteranRatio 记账规则，完整来源全局规则保真仍是后续工作。

## 数量、寿命与保存

初始随机箱数量取玩家数与 CrateMinimum 中的较大值，再受 CrateMaximum 限制。默认两人局为两个随机箱。每个箱子的寿命在 CrateRegen 的半倍到两倍之间随机取值；默认规则在 30 Hz World 中对应 2,700～10,800 tick。开启补给箱时，到期及拾取会补箱，奖励执行前完成拾取补箱的随机消耗。

World55 在既有核心记录后增加有界的 CrateLifetimes 扩展，保存每个箱子的剩余时间。App11 格式不变；旧 World54 和旧来源包继续使用自己的嵌入规则与能力边界。新来源包需要 Scene26，LAN43 区分新的模拟行为。测试夹具适配了新扩展，仍检查旧格式和非法数据拒绝。

## 证据与范围

独立来源包括本地原始 INI、`original-crate-unit-source.json` 和可重复提取的 `original-crate-runtime.json`。后者记录已识别 GAME.EXE 的 SHA-256、反汇编片段及寿命常量，覆盖奖励抽取、钱箱、单位箱、经验设置、放置次数、到期替换和初始数量。

专项入口为 CTest `ra2.source_crates`，对应 `--source-crate-regression`。实际旧存档夹具保存在本地 `review_out/project-review-20261115/source-crates-baseline/`，其 `files.json` 记录归档哈希；兼容性检查会读取这些文件。

修复前分别保留十八条随机箱失败和两条经验值失败。两种构建的机制专项各通过 **64 条断言**：真实移动拾取、三种模式的完整可奖励车辆池、矿车和 MCV 优先、钱箱范围、水上转换、升级及范围、治疗／揭示、真实击杀晋升、World55/App11 精确续档、损坏计时扩展拒绝，以及实际归档 World54/App11 的恢复。

机制夹具会提供隔离的地形、对象或明确状态。单位随机池夹具没有己方建造厂且资金为零，防止原版矿车／MCV 优先条件覆盖普通抽奖。它们用于验证机制；四局普通开局另使用默认资金、未展开 MCV、生成地图和实际 AI，不向主分支提供额外基地、兵力或游戏命令。
