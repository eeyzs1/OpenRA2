## 导出和检查

在项目根目录执行，使用已有本机原版 MIX：

```powershell
python tools/ra2pack/gen_native_maps.py all01t.map
python tools/ra2pack/gen_native_scene.py all01t.map
cmake --build build --config Release --target ra2
ctest --test-dir build -C Release -R '^ra2.(native_scene|native_scene_assets|app_state)$' --output-on-failure
```

完整 `gen_assets.py` 在源地图存在时也会导出此场景；按类型增量导出不会重新导出它。生成文件位于忽略目录 `assets/maps/native/all01t/`，不提交原版素材。

| 文件 | 内容 |
|---|---|
| `scene.ini` | 房屋、原始类型物理属性和全部初始记录；保留原对象键、标签、命令与原始记录文本 |
| `scene-report.json` | 原版 rules/art、SHP、调色板、VXL/HVA 和附属层的来源及 SHA-256 |
| `actors/` | 每种建筑的正常/损坏姿态、显式换色遮罩，以及民用车辆八方向图 |

`--native-scene-regression <输出目录>` 是开发验收入口，通过实际引擎加载、存读档、登载/卸载和绘图。CTest 输出在 `build/native-scene-audit/`，包含自由女神像、华尔街、盟军基地的 1280×720 / 1920×1080 六张画面。普通战役菜单不使用这个入口。

## 已接入的原始数据

- 每个原始类型保留独立身份；源规则与地图局部规则合并后，实际实体读取其 HP、护甲、视野、造价；建筑另读取脚印、供电、驻军容量、可占领和通行属性。自由女神像采用本关 10000 HP、原始已损坏状态 5117 HP 和 3×3 脚印；谭雅采用本关 250 HP。
- 房屋采用原始资金、国家、配色及有向盟友位图。盟友关系按发起方读取，不能把全部 AI 房屋自动视作盟友。本关初始资金 4000；盟军友军基地的 Grey 为 RGB `131,131,131`。
- 初始实体直接从原地图记录创建，不附赠遭遇战 MCV、矿车或通用增援。保留源对象键和标签，供后续原版触发器关联。登载后的乘员仍保留原身份、局部规则和标签，卸载不变回普通模板。
- 每种建筑使用自己的原始 SHP 和剧场/专用调色板，保留画布、帧偏移、正常/损坏体及原始阴影。自由女神像使用 `cgnewy04.shp` / `liburb.pal`。`IdleAnim` / `ActiveAnim` 等附属图层合成原定义的 `LoopStart` 静态姿态，国旗不再只剩旗杆。
- 换色遮罩只标记原始调色板 16–31 号索引，采用源调色板亮度，避免把暗部统一抬亮或误改自然红色像素。房屋颜色缓存按实际 RGB 区分；现有军用 SpriteBank 在原版场景中也选择这些房屋颜色。
- 民用车辆使用各自的原始 VXL/HVA 和既有体素光栅器，不再共用坦克外形。本关七种民用车辆的源模型均没有阵营色索引，保留原车色，遮罩应为空；素材检查同时验证这一点。军用单位仍使用既有动作素材库，尚未逐类验证其与本关原始类型的全部差异。

## 模块与状态

离线导出由 `tools/ra2pack/gen_native_scene.py` 负责；模拟由 `world_native_scene.cpp` 负责；原始定义/身份声明在 `native_actor_types.h`；表现由 `game_native_actors.cpp` 负责。实体查询使用 `unitDef(actor)` / `bldDef(actor)`；生产表查询仍可按普通枚举。内部 `NativeVehicle` 不可直接生产或脱离原定义生成，不要求普通单位语音配置。

定义是共享的不可变对象，名字指针跟随其所有者，复制 World 后仍有效。实体批以 World v31（`RA2WRLDV`）增加有界源场景、当前有向盟友关系、实体和嵌套乘员身份；后续 v32 继续保留这些字段，它们全部参与 checksum。读档先重建定义再验证实体，不保存缓存指针。当前盟友关系单独保存，后续脚本改变它后不会被初始源数据覆盖。

应用 v10（`RA2GAM10`）在 v9 的原始建筑类型记忆上另存观察时的图像帧；失去视野后仍显示观察时的原建筑、脚印、归属、损坏姿态和墙体连接。当前 World v41 保存桥梁分层、修桥意图、场景破坏开关、闸门阶段、事件实例、原生导弹及队伍命令状态，读取保留 v40/v39/v38/v37/v36/v35/v34/v33/v32/v31/v30/v29 的原生格式兼容；应用继续兼容 v9/v8/v7。LAN 模拟协议为 v18，Welcome 布局未改。Scene v3 补齐小屋免伤、修桥属性和单位净空，见 [修桥批](native-bridge-repair.md)。渲染、纹理缓存和派生房屋颜色不消耗模拟 RNG，不加入 checksum。

场景加载和存档恢复先在临时 World 中完成验证，失败不替换当前对局。非阻挡道具与其他建筑重叠时，其销毁只能清理属于自己的占位，避免误擦相邻建筑脚印。

## 仍需实现

1. 原始组队、脚本、事件和动作运行状态；房屋移交、发现/选择/受击条件、局部变量、摄像机/输入锁、雷达提示、原版文本/语音、任务胜负及增援。原始标签目前只保存关联身份，尚不触发这些行为。
2. 全部原始单位/武器/生产规则。当前只覆盖上列物理字段；源 `OriginalSpeed`、`Primary` / `Secondary` 和完整原规则保存在包内，但未全部应用。战斗行为仍部分继承既有类型，不能作为原版规则一致的证明。
3. 原始命令、步兵子格和完整朝向。当前仅对 `Sleep` 保留睡眠语义，其他初始命令还未逐种执行，位置暂使用格中心，朝向量化为八方向。`Significant` 等源标记尚未形成任务胜负逻辑。
4. 建筑及附属层循环动画、建造/倒塌、火灾、完整损坏动画和军用类型专用动作。现有正常/损坏静态姿态不能代替这些过程，动画时序也尚未按原引擎校准。
5. 地表对象及墙体/桥梁覆盖物现已接入初始姿态，见 [地表批](native-scenery.md)，高架桥已接入 [双层通行](native-bridges.md)。完整坍塌和修复、沙袋碾压、树木细分占位及矿井动画仍待实现；原始坡型、地表速度、建筑许可和镜头 `LocalSize` 限界继续待校准。

## 本批验证（2026-11-14）

Release 完整 90 项首次运行耗时 811.29 秒：85 通过、空战役矩阵 1 项按约定跳过、4 项失败。失败来自两个问题：交通损坏存档测试仍按旧文件末尾定位，以及内部 `NativeVehicle` 被错误计入普通语音必需配置。已修正测试偏移和语音配置范围；交通、语音、EVA、表现回放连同场景、存档、交互和网络等相关 15 项复跑全部通过，82.32 秒。该结果不写作完整 90 项全部通过。

最终源调色板修正及 v8 兼容夹具完成后，Release 场景/素材/应用存档三项再次通过，10.04 秒。素材检查逐条比对全部 249 条源记录、68 个类型的物理属性及原始文件哈希；无附属层的建筑另直接核对源调色板像素与换色亮度。实际登载、存档后 120 tick、卸载、当前盟友关系、重叠道具清理和六次实绘均通过。

相关 ASan 九项通过，119.74 秒；最终应用兼容和场景两项再次通过，80.98 秒。没有报告内存错误。它们是机制及画面检查，不是原版任务通关、全量 ASan 或人工整局验收。

随后补齐生成接口的浮点坐标/原始朝向边界检查：巨大有限坐标在转整数和分配实体前拒绝，失败保持 checksum。Release 场景/素材两项通过，5.52 秒；ASan 场景通过，42.51 秒。最终固定车色素材检查通过，0.90 秒。
