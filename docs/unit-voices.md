# 原版单位语音

选择、移动、攻击和采矿指令已接入原版录音。当前本地素材导出 **597 个 WAV、149 个声音组、79 个含阵营变体的配置**。70 个内部单位类型中，66 个有原版声音；舰载黄蜂、米格子单位的原规则没有语音，中国扩展 PLA/99 式没有原版定义，保持静音。

## 原始素材与提取

```powershell
python tools/ra2pack/gen_voices.py
```

工具读取本地 `tools/ra2pack/game/` 的 MIX。RA2 单位优先使用原版 `rules.ini/sound.ini`，YR 新单位使用 `rulesmd.ini/soundmd.ini`。两代档案中都使用同名 `audio.idx/audio.bag`；必须从同一个包含它们的 MIX 配对，不能分别用全局最后命中的文件。只有当前版本没有某个样本时，才搜索另一套真实原始音频。

输出位于忽略目录 `assets/sfx/voices/`：`manifest.ini` 描述单位/阵营/动作到原声音组的对应关系，WAV 保存完整解码数据，`source_report.json` 记录源 MIX、样本、帧数、采样率和压缩数据/PCM 的 SHA-256。没有归一化、截短、合成或随机变调。完整 `gen_assets.py` 同样导出此目录；局部图片导出不改声音。

运行前必须准备语音清单及其中引用的文件；损坏或缺失会报告 `VOICE-MISSING` 并拒绝启动。原规则本来无语音的类型使用显式空配置，不用其他单位冒充。启用的 Mod 可按同名 WAV 路径覆盖样本，也可提供 `sfx/voices/manifest.ini`，按节与字段叠加组/动作配置；空动作值可关闭对应语音。

## 运行时行为

`src/sfx/voices.cpp` 在音频初始化时预载并验证素材，避免第一次选择时读文件。每次点选、框选、同类选择或编队召回只选一名代表播报，优先级取自原声音组，平级保留选择顺序。

移动和攻击只使用模拟实际接受指令的单位。采矿同样只记录执行了命令的矿车；有专用采矿组时优先使用，否则使用该单位原有的移动组。事件保存当时的单位类型和阵营，后来阵亡、被俘或实体编号复用不会换成新单位的声音。仅本地玩家的命令回应，AI 内部调动和远端玩家不播报。

单位语音共用一个通道，新的有效指令可以打断选择语音，连续点击有限流，同组多条录音避免紧接着重复。保持原采样率、正常音调和声音组音量，服从主音量；静音立即停止，换局/读档停止旧回应。声音变化使用独立的表现 RNG，不进入 World、网络校验或存档格式。

## 已验证

- Release 相关十项通过，43.13 秒，覆盖语音、独立解码、交互、经济、编队、攻击、应用/战役存档、网络协议和表现隔离。
- ASan 相关三项通过，21.38 秒，覆盖语音、编队和网络。
- 语音专项实际初始化音频设备并开始播放；测试将进程混音器静音，不打扰用户。覆盖点选/框选、部分接受、拒绝、采矿、远端隔离、编号复用、节流/打断、静音及播放过程中 300 tick 的相同战斗回放。
- 六条 RA2/YR 原版录音重新包装为标准 IMA WAV，使用 FFmpeg 独立解码；PCM 与导出 WAV 逐字节一致。检查保留了原始帧数和采样率。

```powershell
ctest --test-dir build -C Release -R '^ra2.unit_voices$' --output-on-failure
ctest --test-dir build -C Release -R '^ra2.unit_voice_codec$' --output-on-failure
```

独立解码检查需要 FFmpeg，未安装时明确跳过。证据在 `build/unit-voice-final-tests.log`、`build/unit-voice-audit.txt`、`build/unit-voice-codec/comparison.json`、`build-asan/unit-voice-tests.log`。本批没有重跑全量套件。

## 剩余差距

后续已接原版盟军/苏军 EVA 与 RA2 配乐，见 [原版 EVA 与配乐](native-audio.md)。单位部署/特殊动作/受惊等声音尚未整体接线。MCV、运输船等在模拟中共用类型，声音阵营按命令时的玩家阵营解析；被俘后的原生型号身份需随完整单位模型修正。当前播报优先级、打断节奏和整体混音尚未完成与原版逐项对照及人工听感验收。武器音效与完整战役也不能由本专项证明还原完成。
