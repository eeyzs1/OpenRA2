# 战役内容状态

当前不附带战役关卡。之前的 32 关融合任务和 38 关近似官方任务，以及遗留任务文件、地图和批量生成器，已从当前版本撤下。它们是项目生成的原型，不是经过还原验收的 RA2 / 尤里的复仇战役。

旧内容保留于 Git 提交 `e8ffcea` 及更早历史，不作为正式内容继续维护。内置 32 关回退和 `--export-assets` 的旧战役生成路径也已移除，空列表不会自动恢复原型关卡。

保留的基础设施包括任务定义、目标清单、阶段、计时、触发器、科技限制、简报和进度管理。自定义关卡仍可通过启用的 Mod 或 `userdata/content/campaigns/missions.csv` 安装；没有已安装关卡时主菜单不显示战役入口。`mods/ExampleCustom` 是默认关闭的开发示例。

`assets/scripts/*.lua.example` 也是默认关闭的示例，不是战役任务实现。以后制作原版关卡，应先完成一关的地图、初始部队、事件顺序、目标对象和胜负条件还原，再扩展关卡数量。

本次撤下内容没有运行或重整测试。旧战役矩阵依赖已撤下的原型，不能继续用它证明战役完整性，后续在测试重整阶段处理。
