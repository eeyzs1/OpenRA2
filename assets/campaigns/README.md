# 战役内容状态

当前目录登记一关：盟军第一关 `all01t`（孤独守卫）。只有本地已导出原版地图、Scene16 和 CSF 任务文字时才安装该入口，素材缺失不会生成替代地图。主菜单「战役」进入简报，再点击「开始任务」。原地图控制八个阵营、资金、生产、部队和胜负，遭遇战设置不会覆盖它。

之前的 32 关融合任务和 38 关近似官方任务，以及遗留任务文件、地图和批量生成器，已从当前版本撤下。它们是项目生成的原型，不作为 RA2 / 尤里的复仇原版战役重新加入。

旧内容保留于 Git 提交 `e8ffcea` 及更早历史，不作为正式内容继续维护。内置 32 关回退和 `--export-assets` 的旧战役生成路径也已移除，空列表不会自动恢复原型关卡。

保留的基础设施包括任务定义、目标清单、阶段、计时、触发器、科技限制、简报和进度管理。自定义关卡仍可通过启用的 Mod 或 `userdata/content/campaigns/missions.csv` 安装；没有已安装关卡时主菜单不显示战役入口。`mods/ExampleCustom` 是默认关闭的开发示例。

2026-11-13 已补齐任务运行时与脚本声明状态的存读档，约定和独立机制验收见 [战役与脚本存档](../../docs/campaign-persistence.md)。它不构成任何原版关卡的完成证据。

`assets/scripts/*.lua.example` 也是默认关闭的示例，不是战役任务实现。`all01t` 直接运行原生事件，保留原任务文字和语音键，支持菜单重开、任务续档、作者胜负与通关进度。影片按用户要求排除。

文字由 `tools/ra2pack/gen_native_scene.py` 一并提取；已有 Scene16 可单独运行 `python tools/ra2pack/gen_native_presentation.py` 补齐。正常菜单与续档验证为 `ra2.native_campaign`，24 个文字标签逐项与原始 CSF 对照为 `ra2.native_campaign_assets`。`ra2.native_playthrough` 从同一任务入口开局，以正常可见目标指令完成接管、付费生产、修桥、四舰和补给基地。它是自动操作验收，人工整关及其余原版关卡仍待完成。
